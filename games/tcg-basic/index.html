Como Jogar

Objetivo: Reduza a vida do oponente a 0.

  • Você começa com 20 HP e 0 Mana.
  • A cada turno, sua mana máxima aumenta em 1 (até 10).
  • Arraste cartas da mão para o campo para jogá-las (custam Mana).
  • Arraste cartas do campo para o oponente para atacar.
  • Fases: Principal (jogar cartas) → Batalha (atacar) → Fim.

Dica: Criaturas recém-jogadas não podem atacar no mesmo turno (enjoo de invocação).
